# Shardeum Tokenomics Simulations

A web application for simulating and visualizing Shardeum network tokenomics, validator earnings, and network parameters.

## Features

- Token emissions and distribution visualization
- APR/APY calculations for validators
- Network parameter simulations
- Transaction volume analysis
- Security metrics visualization

## Tech Stack

- React
- TypeScript
- Chart.js
- Tailwind CSS
- DaisyUI

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm start
```

3. Build for production:
```bash
npm run build
```

## Deployment

The application is deployed to Vercel at https://issuance-dashboard.vercel.app/. To get it deployed on the shardeum.org website, run the build command `npm run build` to generate the production files in the `build` folder and then upload them to the [shardeum-live repository](https://github.com/shardeum/shardeum-live). Replace the content of the /shm-tokenomics/ folder with the production files generated by the build command in the `build` folder.
